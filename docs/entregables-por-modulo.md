# Entregables Por Modulo

## Autenticacion Y Sistema General

Debe incluir:

- Pantalla de login.
- Dashboard o pantalla de inicio.
- Menu para entrar a los modulos.
- Feed de novedades o avisos, si el tiempo alcanza.
- Calendario escolar o calendario de turnos, si el tiempo alcanza.
- Gestion visual de usuarios, si el tiempo alcanza.
- Roles simulados, si el tiempo alcanza.

Datos posibles:

```txt
Nombre
Apellido
Usuario
Rol
Estado
```

Preguntas que debe resolver este grupo:

```txt
Que roles existen
Que puede ver cada rol
Que opciones aparecen en el menu
Como se accede a cada modulo
Que informacion se muestra en la pantalla de inicio
Como se simula el inicio de sesion
```

## Laboratorio

Debe incluir:

- Formulario para cargar turno.
- Listado de turnos.
- Edicion o cancelacion de turnos.
- Filtro por fecha, curso o profesor, si el tiempo alcanza.

Datos posibles:

```txt
Fecha
Hora
Profesor
Curso
Laboratorio
Motivo
Estado
```

## Comedor

Debe incluir:

- Formulario para cargar reserva o turno.
- Listado de reservas.
- Edicion o cancelacion de reservas.
- Filtro por fecha o curso, si el tiempo alcanza.

Datos posibles:

```txt
Fecha
Turno
Curso
Cantidad de alumnos
Responsable
Observaciones
Estado
```

## Notebooks Y Accesorios

Debe incluir:

- Formulario para registrar notebook o accesorio.
- Listado de equipos.
- Cambio de estado.
- Asignacion a alumno, docente, aula o gabinete.
- Historial simple de movimientos, si el tiempo alcanza.

Datos posibles:

```txt
Codigo interno
Tipo
Marca
Modelo
Estado
Ubicacion
Responsable
Observaciones
```
