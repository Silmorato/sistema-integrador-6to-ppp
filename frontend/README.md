# Frontend Del Sistema Integrador

Este proyecto contiene el frontend del sistema integrador escolar.

## Como Ejecutarlo

Desde esta carpeta:

```bash
npm install
npm run dev
```

## Estructura

```txt
frontend/
  src/
    componentes/
    datos/
    estilos/
    modulos/
      autenticacion/
      laboratorio/
      comedor/
      notebooks/
```

## Responsabilidades

Cada grupo trabaja principalmente dentro de su modulo:

```txt
Grupo 1: src/modulos/autenticacion
Grupo 2: src/modulos/laboratorio
Grupo 3: src/modulos/comedor
Grupo 4: src/modulos/notebooks
```

Los archivos de `src/componentes`, `src/datos` y `src/estilos` son compartidos.
Si un grupo necesita modificarlos, debe avisar antes.
