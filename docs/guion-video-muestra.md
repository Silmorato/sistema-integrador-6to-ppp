# Guion Para Video De La Muestra

## Objetivo Del Video

Mostrar no solo el sistema terminado, sino tambien el proceso de trabajo, las herramientas utilizadas y lo que el grupo aprendio durante el proyecto.

Duracion sugerida: entre 3 y 5 minutos.

## Estructura Sugerida

### 1. Presentacion Del Proyecto

Ideas para decir:

```txt
Somos estudiantes de sexto año y estamos desarrollando un sistema integrador de gestión escolar.
El objetivo es crear un prototipo frontend para organizar diferentes movimientos de la escuela.
```

Mostrar:

- Nombre del proyecto.
- Pantalla de inicio o login.
- Integrantes o grupos de trabajo.

### 2. Problema Que Se Busca Resolver

Ideas para decir:

```txt
En la escuela hay informacion que muchas veces se registra en distintos lugares.
Este sistema busca centralizar esa informacion en una aplicacion organizada por modulos.
```

Mostrar:

- Menu principal.
- Modulos disponibles.

### 3. Modulos Del Sistema

Cada grupo muestra brevemente su parte.

Grupo 1:

- Login.
- Inicio.
- Usuarios.
- Roles.
- Menu de acceso.

Grupo 2:

- Turnos de laboratorio.
- Formulario.
- Listado.
- Estados.

Grupo 3:

- Reservas de comedor.
- Formulario.
- Listado.
- Cantidad de alumnos.

Grupo 4:

- Notebooks y accesorios.
- Registro de equipos.
- Estados.
- Ubicacion o responsable.

### 4. Herramientas Utilizadas

Ideas para decir:

```txt
Para construir el proyecto usamos HTML y CSS.
Tambien usamos Git y GitHub para guardar versiones y organizar el trabajo.
```

Mostrar:

- Codigo del proyecto.
- Carpetas del frontend.
- Repositorio de GitHub.
- Commits o ramas, si ya las usaron.

### 5. Como Se Organizo El Trabajo

Ideas para decir:

```txt
El proyecto esta organizado en carpetas por modulo.
Cada grupo trabaja sobre una parte del sistema para despues integrarlo en una misma aplicacion.
```

Mostrar estructura:

```txt
modulos/
  autenticacion/
  laboratorio/
  comedor/
  notebooks/
```

### 6. Aprendizajes

Cada grupo puede mencionar algo aprendido:

- Como pensar requerimientos.
- Como organizar pantallas.
- Como crear formularios.
- Como trabajar con componentes.
- Como simular datos.
- Como usar Git y GitHub.
- Como dividir tareas.

### 7. Cierre

Ideas para decir:

```txt
Este proyecto es una primera version del sistema.
Actualmente funciona como prototipo frontend en HTML y CSS, pero podria crecer con JavaScript, un backend, una base de datos y usuarios reales.
```

Mostrar:

- Recorrido final por el sistema.
- Pantalla de inicio.
- Modulos principales.

## Recomendaciones Para Grabar

- Hablar claro y breve.
- Mostrar el sistema funcionando, no solo explicar.
- Dividir la participacion entre varios integrantes.
- Evitar leer todo de corrido.
- Mostrar el proceso: carpetas, codigo, GitHub y documentacion.
- Cuidar que se vea bien la pantalla.

## Preguntas Para Preparar Antes De Grabar

```txt
Que problema resuelve nuestro modulo
Que pantallas hicimos
Que datos se cargan
Que acciones puede hacer el usuario
Que herramienta nueva aprendimos
Que nos costo mas
Que mejorariamos en una proxima version
```
